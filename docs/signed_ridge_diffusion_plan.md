# 单通道道路山脊场与冻结 SAM 改造方案

- 日期：2026-10-23
- 状态：代码重构与自动回归已实施；真实预训练 SAM 提示有效性、完整训练及对照实验尚未完成。当前接口和使用方式见 [训练说明](joint_training.md)，验证范围见 [测试记录](testing.md)。
- 目标：以单通道有符号道路山脊场替代双通道点提示热图；SAM 全阶段冻结；监督预训练后，仅对条件编码器与 DiT 进行 GRPO 后训练。

## 1. 设计目标与边界

扩散模型生成道路结构提示，冻结的 SAM 结合图像特征将提示解码为道路分割。监督阶段学习道路几何与有效提示，GRPO 阶段根据最终分割质量优化提示生成分布。

希望扩散模型能够表达遮挡区域的连续路径、细道路宽度、复杂交汇和道路边界等结构变化。使用扩散模型不自动保证这些能力，必须通过确定性提示预测基线、单次采样表现和提示干预实验验证。

第一版明确采用以下范围：

- 单通道连续山脊场，直接作为密集 mask prompt 的来源。
- 不提取离散正负点，不优化点数、峰谷数量或峰谷对比度。
- 条件编码器和 DiT 可训练；SAM 图像编码器、提示编码器、掩码解码器及相关高分辨率投影全部冻结。
- 保留监督预训练，以及 GRPO 中可配置的监督锚定。
- 保持现有图像尺寸、热图分辨率和 DiT 主体，先控制变量。
- 保留 ABC、D 阶段入口，升级训练协议版本。

## 2. 总体架构

```text
输入图像
   ├─ 冻结 SAM 图像编码器 ───────────────────┐
   └─ 可训练条件编码器 → 条件 DiT            │
                           ↓                │
                   单通道有符号提示场       │
                           ↓                │
                     固定尺度映射           │
                           ↓                │
                   冻结 SAM 提示编码器      │
                           └───────────────┤
                                           ↓
                                  冻结 SAM 掩码解码器
                                           ↓
                                       道路分割
```

条件编码器与现有 SAM 图像特征的融合方式沿用当前实现。

| 模块 | ABC 监督预训练 | D：GRPO 后训练 |
| --- | --- | --- |
| 条件编码器 | 更新 | 更新 |
| 条件 DiT | 更新 | 更新 |
| SAM 图像编码器 | 冻结 | 冻结 |
| SAM 提示编码器 | 冻结 | 冻结 |
| SAM 掩码解码器及相关投影 | 冻结 | 冻结 |

冻结同时要求 `requires_grad=False` 和保持 `eval`。ABC 只在 `no_grad` 下调用 SAM 图像编码器提取特征，不计算 SAM 最终分割损失；D 的奖励评分同样可 `no_grad`。SAM 的提示→分割路径对提示场保持可微，接口保留供验证、推理与诊断使用，但训练损失不依赖该路径。

## 3. 山脊场监督目标

### 3.1 数值语义

目标场 `H*` 为 `1 × h × w`，取值范围为 `[-1, 1]`：

| 区域 | 目标语义 |
| --- | --- |
| 道路中心线 | 接近 +1，形成连续山脊 |
| 道路内部 | 从中心线向道路边界逐渐下降 |
| 道路边界 | 从道路内侧低正值或零骤降至背景负值 |
| 有效背景 | 固定为 -1，形成平底 |
| padding | 单独标记，不作为真实背景参与监督或奖励 |

不再沿中心线按固定间隔构造正峰，也不在道路外构造离散负谷。连续山脊和平坦背景不提供唯一的离散极值位置，因此新协议不依赖峰值提取。

### 3.2 初始构造公式

设道路区域为 `M`，中心线为 `C`，`d_boundary(x)` 为道路内部到边界的距离，`d_center(x)` 为到中心线的距离：

```text
H*(x) = a + (1-a) * d_boundary(x)
                    / (d_boundary(x) + d_center(x) + epsilon),  x ∈ M

H*(x) = -1,                                                  x ∉ M
```

第一版使用 `a=0`。中心线像素可以显式赋值为 +1，稳定离散网格上的山脊高度。该公式是几何近似，交汇点和离散边界处需检查实际形状。

它区别于未经归一化的内部距离变换：宽路与窄路的山脊高度尽量一致，而横向响应宽度仍由道路几何决定。

### 3.3 几何与特殊样本

- 同步变换图像与 mask 后构造目标，保持图像、中心线和热图对齐。
- 明确目标构造与降采样顺序，验证半像素坐标、等比缩放和右下 padding 的一致性。
- 统计细道路降采样保留率；不能因热图缩小将道路全部变成背景。
- 空道路图的有效区域为全 -1；不得沿用旧目标的全零约定。
- 全道路、接触图像边缘、极细道路及退化骨架都需要定义距离变换行为。
- padding 使用独立有效区域掩码，并采用统一的 SAM 输入数值约定。
- 第一版使用硬边界。若出现边界振荡或训练不稳定，再对比约一个热图像素宽的过渡带。

山脊形状是预训练先验，不是后训练期间强制满足的后处理约束。GRPO 可以调整局部提示结构，监督锚定用于限制无意义漂移。

## 4. 单通道扩散与 SAM 接口

### 4.1 扩散数值域

- DiT 输入、输出通道数统一为 1。
- 直接以有符号目标场进行扩散训练。
- 移除旧的 `[0,1] → [-1,1]` 目标变换和采样后的逆变换。
- 重新处理依赖旧背景语义的采样均值补偿及热图损失分区。
- 带噪状态 `z_t` 不限制在 `[-1,1]`。
- 最终提示场的范围控制与 SAM 输入映射独立定义，训练、验证、推理保持一致。

如对终端提示进行裁剪或有界映射，GRPO 仍以原始高斯转移动作计算轨迹概率，不能用裁剪后的动作冒充原始高斯样本。

### 4.2 提示尺度

初始采用固定映射 `U = s * H`，其中 `s` 为验证集选择的固定尺度。第一版不增加可训练适配器，以便确认改进是否来自扩散提示本身。

SAM 接口支持单通道，不等于它天然理解山脊场。正式训练前先运行：

```text
标注 mask → 目标山脊场 → 固定尺度映射 → 冻结 SAM → 分割评价
```

对比普通二值 mask 提示及若干固定尺度，检查输入可用性和提示敏感性。此实验是接口诊断，不是整个模型的理论性能上限。若目标场本身难以有效引导 SAM，先调整表示或输入映射，再进行扩散训练。

## 5. ABC：监督预训练

ABC 只训练扩散分支，损失由扩散、场重建和辅助监督组成：

```text
L_ABC = L_diff
      + lambda_heat * L_field
      + lambda_aux * L_aux
```

| 损失 | 作用 |
| --- | --- |
| `L_diff` | 扩散噪声预测，学习条件生成过程 |
| `L_field` | 重建单通道山脊场 |
| `L_aux` | 保留条件分支的道路、骨架辅助监督 |

冻结 SAM 仅以 `no_grad` 提取图像特征，不参与 ABC 损失。原一步重建与纯噪声完整采样两条 SAM 分割监督通路不再用于训练：完整可微采样成本高，且训练目标聚焦于山脊场几何与扩散分布。SAM 可微提示→分割接口仍保留，但只用于验证、推理与诊断，不是训练需求。

`L_field` 按中心线邻域、其余道路、边界外窄带、远端背景分别归一化，避免大面积 -1 背景主导训练。区域应明确划分，缺失区域跳过，避免除零。

第一版不新增高频、锐度或细节丰富度损失。不能仅以扩散损失或一步重建误差下降判断收敛；验证阶段仍需将完整采样场送入完整 SAM 解码，检查实际分割质量。

## 6. D：仅更新扩散分支的 GRPO

### 6.1 候选生成与评分

对同一图像独立生成 G 条扩散轨迹：

```text
H_g ~ p_theta(H | I)
P_g = SAM_frozen(I, H_g)
M_g = P_g >= threshold
R_g = reward(M_g, target)
```

每张图像独立构成一组，计算组内优势。SAM 使用确定性分割评分，不再采样终端 Bernoulli 掩码。

保留：

- 扩散随机转移和轨迹记录。
- 条件编码器与 DiT 的概率重放及 Gaussian GRPO。
- 固定参考条件编码器和参考 DiT 的 KL 约束。
- 可配置的监督锚定。

删除：

- 终端 Bernoulli 动作和 log-probability。
- SAM 终端策略损失、终端 KL 和参考 SAM 解码器。
- SAM 优化器参数和相应终端策略日志。

采样与重放保持一致的模型模式、调度和概率定义。确定性终端步骤不能直接套用非退化 Gaussian log-probability。

### 6.2 目标与奖励

```text
L_D = L_GRPO_diff
    + beta * L_KL_diff
    + lambda_anchor * L_supervised

R = w_iou * IoU + w_cldice * clDice + w_path * R_path
```

“只优化扩散分支”约束的是参数范围，不意味着必须删除监督损失。第一版保留小权重监督锚定，其中 `L_supervised` 采用第 5 节的新 ABC（`L_diff + lambda_heat*L_field + lambda_aux*L_aux`），不含 SAM 分割项；并提供关闭锚定的消融实验。

先用 IoU、clDice 跑通，根据连接性问题再开启路径项。现有路径奖励是抽样代理，不是正式 APLS。候选比较采用固定、可复现的奖励采样规则，减少非策略随机性。

不奖励点数、峰谷数量、幅值对比或高频细节。所有几何变化最终都应服务于分割质量。

单通道改变高斯联合 log-probability 和 KL 的尺度，需要监测裁剪比例、KL 和更新幅度，重新校准相关超参数，不能直接假定旧值等效。

## 8. 检查点与兼容性

新协议与旧双通道、SAM 联合微调检查点不兼容，禁止直接 `--resume`。

新快照至少记录：

- 训练协议与目标表示版本。
- 输入输出通道数。
- SAM 全冻结标识。
- 提示尺度和终端映射配置。
- 扩散采样调度与 GRPO 相关配置。
- 参考条件编码器和参考 DiT 状态。

旧权重只允许显式迁移形状兼容部分。DiT 输入投影、输出头及优化器状态不能默认复用，迁移时应报告跳过和重新初始化的参数。移除 `ref_sam_decoder` 的创建、保存与恢复要求。

## 9. 测试与验收

### 9.1 功能测试

- 直路、弯路、交叉口、近邻道路、细路、空图和边界接触样本的目标语义正确。
- 翻转、旋转、缩放和 padding 后，图像、mask、中心线与场对齐。
- 单通道扩散训练、采样、验证与推理可运行，数值域一致。
- ABC、D 更新前后 SAM 参数及状态保持不变。
- SAM 的提示→分割路径对提示场保持可微，可在验证、推理与诊断中使用；ABC 与 D 训练损失不依赖该路径。
- D 阶段只有条件编码器与 DiT 更新，参考模块保持固定。
- 旧新策略在初始重放时概率一致，奖励按图像分组。
- 常量奖励、空图、无有效区域等边界情形有明确行为。
- 新协议保存恢复一致，旧协议恢复被明确拒绝。

重点调整现有 `tests/test_joint_rl.py`、`tests/test_joint_training.py`、`tests/test_engine_pipeline.py`，以及数据、扩散、SAM 和推理相关测试。

### 9.2 指标

| 维度 | 指标或检查 |
| --- | --- |
| 区域质量 | IoU、F1 |
| 结构质量 | clDice、断裂与错连；必要时正式路径评估 |
| 边界质量 | 边界 F1、细道路保留情况 |
| 生成与训练稳定性 | 空预测率、场分布、组内奖励方差、KL、裁剪比例 |
| 提示有效性 | 正常提示、零提示、打乱提示时的输出差异 |
| 成本 | 显存、吞吐、单次推理延迟 |

提示干预用于判断 SAM 是否使用生成场。零提示与打乱提示可能偏离训练分布，因此不能仅靠一个干预结果下结论，还应检查合理局部扰动与不同采样候选的响应。

主要报告固定采样协议下的单次生成表现及跨种子波动。多候选最优分割只作潜力诊断；没有可部署的选择器时，不报告为实际部署效果。

## 10. 实施顺序与对照实验

### 第一步：目标场与 SAM 接口

实现山脊场构造，验证特殊几何与尺度映射。将标注构造的场直接输入冻结 SAM，确认提示有效后进入训练。

### 第二步：监督链路

接通单通道 DiT、ABC 损失和全冻结 SAM 图像特征。通过冻结测试后做小样本训练，并在验证时检查纯噪声完整采样场经完整 SAM 的分割与场分布，而不只看训练损失。

### 第三步：扩散 GRPO

移除终端分割策略，接通确定性评分、扩散轨迹更新、参考 KL 和监督锚定。先做短测检查概率重放、奖励方差、参数变化与显存。

### 第四步：完整评估

至少比较：

1. 确定性网络预测同样的单通道提示场，接相同冻结 SAM。
2. 扩散提示场，仅监督训练。
3. 扩散提示场，监督训练后进行 GRPO。
4. GRPO 关闭监督锚定的消融。

根据结果再增加普通二值 mask 提示、边界过渡带或提示分辨率对照。尽量匹配条件输入、SAM、训练预算和推理成本，并明确无法完全匹配的差异。

## 11. 主要风险与决策条件

- **表示失配：**冻结 SAM 可能不能有效解释地形场。先完成目标场输入实验，必要时调整固定映射或目标表示。
- **背景主导：**大面积 -1 可能诱发退化。采用区域平衡监督，同时监测实际生成与分割结果。
- **分辨率不足：**热图可能无法表达细路。先测量损失发生在哪一步，再决定是否提高分辨率。
- **提示无效：**不同场产生近乎相同输出，GRPO 缺乏有意义的奖励差异。检查接口、提示尺度和模型条件依赖。
- **生成变化无用：**候选只有噪声差异，没有结构差异。通过候选分割与确定性基线验证，而不直接奖励多样性。
- **策略更新不稳：**高维轨迹概率比易变化。监测 KL、裁剪和奖励方差，校准更新强度。
- **采样潜力不等于推理收益：**单次结果和多候选最优结果分开报告。

只有在冻结 SAM 路线已经有效、且证据指向解码适配瓶颈时，再将解冻 SAM 解码器作为后续实验。第一版的核心问题是：单通道山脊场是否能有效提示冻结 SAM，以及扩散轨迹 GRPO 能否进一步改善道路细节和连通性。
