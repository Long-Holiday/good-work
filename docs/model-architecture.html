总览：三个系统合作完成分割

可训练的部分

ConditionEncoder 把 RGB 细节和 SAM 图像特征整理成四尺度条件。条件 DiT 根据这些条件逐步去噪，生成单通道山脊场。

冻结的部分

SAM2.1 Hiera-B+ 提供图像特征，并把山脊场当作密集 mask 提示进行解码。图像编码器、提示编码器、掩码解码器以及高分辨率投影都不更新。

不要把旧文档里的独立 A/B/C 阶段或“热图取峰值 → 正点/负点”套用到这里。当前主链路不取离散峰值，不使用点提示或框提示；稀疏点接口仅作为保留的工具路径。

第一处难点：山脊场究竟表示什么？

标注掩码 M 只回答“这里是不是道路”。山脊场 H* 进一步表达“道路中心在哪里”。它不是道路概率，因此可以为负数，也不需要先经过 sigmoid。

道路内部 H*(x) = d_boundary / (d_boundary + d_center + ε)
骨架像素显式设为 +1；有效背景 = −1；padding = 0。

d_boundary 是道路内到背景距离减一后截到非负；d_center 是到骨架的距离。目标先在原始标注分辨率构造，再按对应区域最大池化到 256×256，尽量保留细道路与中心线。

原始二值掩码道路 M / 背景
→
骨架 + 距离变换构造原图分辨率的 H*
→
区域最大池化目标变为 1×256×256
→
有效掩码 + 四分区屏蔽 padding / 平衡场重建

四个监督区域分别是中心线邻域、其余道路、道路外侧窄带、远端背景。它们只负责组织场重建损失，不是四个生成输出通道。当前输出始终只有一个通道。

源码：diffpeak/data/ridge.py:165–222、323–418；diffpeak/models/diffusion.py:256–307。

第二处难点：RGB 与 SAM 特征怎样融合？

SAM 特征提供预训练的视觉表示，独立 RGB 细节分支保留可学习的局部纹理。二者在 ConditionEncoder 中融合；SAM 自身不因这次融合而更新。

每个基础卷积块为 Conv2d → GroupNorm → SiLU。细节分支先把 1024² 降为 512²，再降为 256²，接两个残差块。后续步长卷积形成 256、128、64、32 四个空间尺度。

“C256”中的 256 指空间边长，不是通道数。例如 C256 的形状是 B×64×256×256，而 C32 的形状是 B×256×32×32。别把通道轴和空间轴看反。

源码：diffpeak/models/conditioning.py:109–150、253–279。

第三处难点：DiT 如何在二维场上工作？

DiT 不直接输出道路类别，而是预测当前带噪场里的噪声 ε。扩散调度器利用这个预测计算下一步状态。每一次采样调用的是同一套 DiT 权重，并不是串联 20 个不同模型。

把二维小块变为 token，再拼回二维图

空间条件：加到 token 上

四尺度条件分别通过 1×1 卷积投影为 256 通道，双线性对齐到场的 256² 分辨率后逐像素相加，再用 8×8 卷积切块，得到图像条件 token。这里没有把四尺度直接拼成一条长序列，也没有图像条件 cross-attention。

时间条件：调制每个 block

t 先做正弦编码，再经 MLP 得到时间向量。每个 block 根据它生成六组参数：Attention 与 MLP 两支各有 shift、scale、gate。时间步说明“现在还剩多少噪声”，不是位置坐标。

单个 Transformer block 的局部图解

时间 t → 正弦编码 → 时间 MLP → c_t
                              │
                    SiLU + Linear → 6 组调制参数
                              │
x → LayerNorm → shift/scale → Self-Attention → × gate_attn → + x → x′
x′→ LayerNorm → shift/scale → MLP(256→1024→256) → × gate_mlp → + x′ → 输出

调制公式：modulate(u) = u × (1 + scale) + shift
残差公式：x′ = x + gate × branch(x)

Self-Attention 使用 8 个头，每头 32 维；dropout 为 0。MLP 使用 GELU。adaLN-Zero 将调制层零初始化，使 block 初始为恒等映射；最终输出线性层也零初始化，因此未训练模型最初预测的噪声为 0。

源码：diffpeak/models/dit.py:157–214、278–309、330–378、432–473。

第四处难点：为什么训练时有两种场？

当前监督阶段叫 ABC，它在同一次训练中同时优化下面两条路径。两条路径共用条件编码器、DiT 和冻结 SAM；只是带噪场的起点不同。

路径一：随机时间步单步重建

真实目标 H*训练时存在
→
加噪得到 z_t随机 t / 随机 ε
DiT 一次前向预测 ε_pred
→
代公式还原 Ĥ裁剪到 [−1, 1]

Ĥ 进入冻结 SAM 得到重建分割；同时可以比较预测噪声与真实噪声，以及重建场与目标场。

路径二：纯噪声多步生成

纯高斯噪声不从 H* 加噪出发
→
DiT + DDIM ×20保留计算图
生成场 H_gen裁剪到 [−1, 1]
→
冻结 SAM生成分割监督

它的起点与推理一致。训练时仍用真实掩码计算分割损失，梯度经过全部可微采样步骤回传。

z_t = √ᾱ_t · H* + √(1−ᾱ_t) · ε
Ĥ = clamp((z_t − √(1−ᾱ_t) · ε_pred) / √ᾱ_t, −1, 1)

ᾱ_t 是噪声调度中的累计信号系数。1000 个训练时间步是噪声强度的离散刻度；20 次采样是从这些刻度选出较少转移来生成场。训练的单步噪声监督无需每次走完 1000 步。

五项损失，各自监督哪里？

L_ABC = L_diff + 0.1 L_heat + 0.2 L_aux + 1.0 L_seg + 1.0 L_sampled_seg
损失项比较对象 / 内容梯度主要流向
L_diff预测 ε 与实际加噪 ε 的 MSE；只统计有效像素。DiT + 条件编码器
L_heat单步重建场 Ĥ 与 H*；四分区分别平均 MSE，再对非空区平均。默认仅 t<500 的样本参与。DiT + 条件编码器
L_aux辅助道路头、中心线头与标注；各自 BCE + Dice。条件编码器，包括辅助头
L_seg单步重建场经过 SAM 后的分割与掩码比较。穿过冻结 SAM → DiT + 条件编码器
L_sampled_seg从纯噪声生成的场经过 SAM 后的分割与掩码比较。穿过冻结 SAM 和多步采样 → DiT + 条件编码器

两项分割损失均为 BCE + Dice + 0.2 × soft-clDice。BCE 约束像素分类，Dice 约束区域重合，soft-clDice 约束软骨架连通结构。分割在有效图像区域裁剪后计分；上述权重是当前 YAML 设置，可由配置改变。

t<500 的门控只用于 L_heat。当前实现中的重建分割 L_seg 不带这项时间步门控。场 H、SAM logits、sigmoid 概率也不能混用：H∈[−1,1]，logits 无固定范围，概率∈[0,1]。

源码：diffpeak/engine.py:598–642；diffpeak/models/diffusion.py:309–382；diffpeak/losses.py:170–209；configs/3090.yaml:56–60。

第五处难点：冻结 SAM，为何还能回传？

冻结表示“不更新这个模块的权重”，并不表示“输入不需要梯度”。对于固定函数 y=f_W(H)，W 可以保持不变，同时仍能计算 ∂y/∂H。

图像编码器：只提供固定特征

encode() 在 no_grad 下计算特征并 detach。条件编码器仍能根据这些固定输入学习自己的投影、卷积与融合参数。

提示与掩码解码器：传递输入梯度

decode_heatmaps() 不把主体前向放入 no_grad。U=s×H 进入提示编码器，再与图像特征共同解码，分割损失能回到 H。

SAM 两级原始高分辨率 FPN 均为 256 通道。掩码解码器自己的冻结投影 conv_s0 / conv_s1 分别得到 32×256² 和 64×128²。这与条件编码器内部的可训练 1×1 投影并不是同一套权重。

源码：diffpeak/models/sam.py:199–219、269–335、616–766；diffpeak/engine.py:374–405。

D 阶段：结构不变，学习信号变了

D 是可选 GRPO 后训练阶段。仍然只更新条件编码器和 DiT，SAM 仍被冻结。主要区别是用同图多个生成结果的相对好坏，决定哪些扩散动作更值得提高概率。

同图生成 G=4 条轨迹各自从随机噪声出发，记录高斯动作及旧概率
→
冻结 SAM 生成掩码sigmoid 后按阈值确定性二值化
→
奖励转为组内优势当前奖励 0.6 IoU + 0.4 clDice
→
重放扩散转移裁剪策略目标 + 参考 KL + 可选监督锚定

奖励不直接对阈值掩码求导。更新时重新计算每一步动作的高斯概率，用策略梯度把高优势轨迹变得更可能。参考条件编码器与参考 DiT 是冻结副本，只用于 KL 约束，不参与普通推理。

L_D = L_GRPO + β · KL(当前扩散策略 ∥ 固定参考策略) + α · L_ABC
当前配置：β = 0.01，α = 0.01，G = 4。

每个扩散转移的标准差至少为 0.02，末步也有探索噪声。轨迹概率使用裁剪前的原始高斯动作计算；最终给 SAM 的场再裁剪到 [−1,1]。因此即使 DDIM 的 eta=0，这里的完整采样也不是无随机扰动的确定性过程。

源码：diffpeak/joint_rl.py:1–42、514–566；diffpeak/models/diffusion.py:387–448、497–525；configs/3090.yaml:71–89。

推理时只保留哪条路径？

  1. 预处理。 RGB 转为 [0,1]，按长边缩放到 1024，并在右/下补零到 1024²；记录有效尺寸。
  2. 提取固定图像特征。 SAM 输入按 ImageNet 均值/方差归一化，提取 low 与两级 high FPN 特征。
  3. 编码图像条件。 ConditionEncoder 接收 RGB 和完整 SAM 特征，输出四尺度条件。辅助 logits 不用于预测。
  4. 从纯噪声生成场。 同一个 DiT 在 DDIM 调度下执行 20 次转移，输出 1×256² 山脊场。
  5. 映射为密集提示。 终端场裁剪到 [−1,1] 后，U=s×H，当前 s=1；有效区域外提示归零。提示编码器不接收点或框。
  6. 解码与恢复。 SAM 输出的低分辨率 logits 双线性上采样到 1024²；sigmoid 得到概率，裁去 padding 并恢复原图尺寸，按当前阈值 0.5 输出二值道路掩码。

推理没有真实掩码、H*、随机时间步重建分支或训练损失；也不需要参考策略。图像条件仍会在每一次 DiT 去噪中使用。20 步只重复去噪器，不重复运行 SAM 图像编码器。

几个容易混淆的问题

这是两个 SAM 吗？

不是。代码由一个 RoadSAM 包装 SAM2。一次图像编码得到的特征同时供条件编码器与掩码解码器使用。ABC 中两种场需要分别做提示编码与解码，但不是两套独立 SAM 权重。

生成器是 U-Net 吗？

不是。去噪器是 ConditionalDiT，由 patch embedding、六层 Transformer 和最终场输出头组成。ConditionEncoder 含卷积与下采样金字塔，但它不负责直接输出最终掩码。

辅助头输出与生成山脊场有何区别？

辅助头在 C256 上直接预测道路/骨架两个 logits 通道，负责监督图像特征。山脊场由 DiT 经扩散生成，只有一个通道，并作为 SAM 密集提示使用。

“潜变量”是否意味着存在 VAE？

这里的 latent/state 指单通道带噪道路场。当前链路没有 VAE 编码器或解码器，也没有先把 RGB 压入图像生成潜空间；扩散直接发生在 256² 的场表示上。

H=0 是否表示没有提示？

不是。“一个全零 mask 张量”仍然会走 SAM 的 mask 提示编码支路；它与 masks=None 不是同一接口含义。padding 的零值则通过有效尺寸被显式屏蔽。
